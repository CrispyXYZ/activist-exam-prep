# 砺学题库

一个由纯 HTML、CSS、JavaScript 构成的离线题库练习前端，内容来自当前目录的 `题库.docx`。

不需要安装依赖，不需要后端，直接打开 `index.html` 即可使用。学习记录保存在浏览器 `localStorage` 中。

## 快速开始

直接双击 `index.html`，或在当前目录启动一个静态服务器：

```powershell
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

> 如果浏览器对 `file://` 页面的本地存储有限制，使用上面的本地服务器方式即可正常保存学习记录。

## 功能

### 单题练习

- 每次只显示一道题，答完进入下一题。
- 可按专题、题型筛选，并设置本轮题数。
- 「重 : 轻」权重滑块控制重题与轻题的抽取概率，例如 `7 : 3`。
- 单选题、多选题、判断题提交后自动判分。
- 多选题使用红色题型标签、红色「多选」提示条与选项字母强调，并提示「少选、多选均不得分」。
- 填空题、简答题提交后展示参考答案，由使用者点击「我答对了 / 我答错了」自行判分。
- 答案区域同时展示题型、重/轻、知识点分类和原题位置。
- 键盘支持：`A–E` 选择选项，`Enter` 提交或进入下一题（判断题点击选项后按 `Enter`）。

### 题组模拟

- 一页生成一组少量题目，可分别设置单选、多选、判断、填空、简答的题量。
- 选择题与判断题交卷后自动判分；填空、简答展示答案后自评。
- 交卷前会提示未作答题数；未作答的客观题按错误记录。
- 交卷后显示客观题得分、主观题自评进度，并支持逐题修改自评。

### 题库浏览

- 浏览全部题目。
- 按题干、选项、答案、专题关键词搜索。
- 按专题、题型、重要程度、练习状态筛选。
- 点开题目查看完整题干、选项与答案；答案默认隐藏。
- 支持从详情页直接开始练习该题。

### 学习统计

- 页面右上角常驻显示三色计数：绿色「正确」、红色「错误」、灰色「未练习」，并保留题库总数与累计正确率。
- 通过题目、错误题目、未练习题目三种互不重叠的状态。
- 已练题数、累计练习次数、总正确率、题库通过率。
- 按题型、按专题拆解掌握情况。
- 最近作答记录。
- 支持「只练错题」和清空学习记录。

## 统计口径

- **通过**：该题最后一次作答结果为正确。
- **错误**：该题最后一次作答结果为错误。
- **未练习**：该题没有判分记录。
- 以上三项互不重叠，数量之和等于题库总题数。选择题、判断题提交即判分；填空、简答题需自评后才进入通过或错误，未自评时仍视为未练习。
- **累计练习次数**：每提交一道题累计一次；同一题重做会继续累计。
- **总正确率**：累计正确次数 ÷ 累计练习次数。
- 填空、简答题在自评后才计入统计；修改自评会更新最后一次结果，但不会重复增加练习次数。

## 抽题权重

滑块取值为 `0` 到 `100`，步长 `10`：

- `70` 表示每次从剩余题目中抽题时，重题权重为 70%，轻题为 30%，界面显示 `7 : 3`。
- 如果某一类题已经抽完，会自动从另一类补足。
- 权重只影响抽中概率，不改变题目本身的难度或分类。

解析规则：

- **知识点分类**：取 `第X部分 YYYYYY` 中的 `YYYYYY`。
- **重要程度**：题干在 Word 中加粗的题目标记为「重」，否则为「轻」。
- **题型**：根据文档中的题型小标题识别；部分没有小标题的题目按选项、答案和题干特征推断。
- **答案**：兼容了文档中的多种答案写法，包括文末括号、独立「答案：」行、下划线内嵌答案、选项内嵌答案等。

未收入题库的内容：

- 党徽党旗条例原文、时政背景介绍等非题目材料。
- 「二十大部分知识点总结」——它是知识点提纲，不是一道可作答的题目。
- 7 条位于「填空题」标题下、但既没有挖空也没有答案的陈述性文字。

## 本地存储

- 存储键：`lishi-question-bank-v1`
- 保存内容：每题作答统计、最近作答记录、练习/题组筛选偏好。
- 清除浏览器站点数据会同时清除学习记录。
- 所有数据仅保存在当前浏览器，不会上传到服务器。

## 兼容性

- 桌面端：Chrome、Edge、Firefox、Safari 的现代版本。
- 移动端：已做响应式布局，题库筛选项在窄屏下默认收起。
- 不依赖任何外部字体、CDN、图片或第三方 JavaScript 库。
